An implementation of **Conditional Flow Matching (CFM)** for generative image modelling on MNIST, developed as part of my bachelor's thesis at the Max Planck Institute for Intelligent Systems. The code is available on [GitHub](https://github.com/LuisBauer22/BA-Basic-functions).

The core idea: train a neural network to learn a velocity field that transports samples from Gaussian noise ($$t=0$$) to the data distribution ($$t=1$$), then generate new images by integrating the learned ODE.

## Method

Given a training image $$x_1$$ and a noise sample $$x_0 \sim \mathcal{N}(0, I)$$, the conditional flow is defined as

$$
\psi_t(x_0) = \bigl(1 - (1 - \sigma_{\min})\, t\bigr)\, x_0 + t\, x_1 .
$$

The network $$v_\theta(x, t)$$ is trained to match the regression target

$$
\frac{d}{dt} \psi_t(x_0) = x_1 - (1 - \sigma_{\min})\, x_0 .
$$

At inference time, new images are generated by solving the ODE from $$t = 0.001$$ to $$t = 1$$, starting from random Gaussian noise.

## Network architectures

All generative networks receive a time input $$t \in [0, 1]$$. It is passed through a sinusoidal embedding followed by an MLP and injected into the network through FiLM layers (Feature-wise Linear Modulation), $$x \leftarrow \gamma(t) \cdot x + \beta(t)$$.

- **DenseNet** – fully connected; $$t$$ (or its embedding) is concatenated to the input.
- **Conv_Net** – convolutional; FiLM on every convolutional layer.
- **U_Net** – U-Net with skip connections; FiLM on every encoder, bottleneck and decoder block.

Architectures are defined in YAML files, so new variants can be added and compared in a grid search without changing the training code.

## Training

- **Checkpointing** after every epoch, so that training can resume on a cluster without losing progress.
- **Fidelity checkpoints** that store the weights at selected epochs, to analyse how generation quality evolves during training.
- **Fixed-t monitoring**, which evaluates the loss on a grid of fixed time values after each epoch to see where the network struggles.
- **Time sampling** either uniformly on $$[0, 1]$$ or from custom distributions via the inverse CDF, for example to oversample high-loss regions near $$t = 1$$.
- **Learning rate schedules**: fixed, cosine annealing and exponential decay.

## Inference and evaluation

New images are generated by solving the learned ODE with `torchdiffeq`. Different fidelity checkpoints can be used on different segments of the integration interval, for example an early checkpoint for the first third and the fully trained model for the rest.

Sample quality is measured with the Fréchet Inception Distance against the MNIST test set, using a pre-trained DenseNet classifier (more than 99% test accuracy) as the feature extractor.
